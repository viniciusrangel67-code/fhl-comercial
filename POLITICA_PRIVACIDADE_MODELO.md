# Política de Privacidade — Modelo

O sistema coleta dados pessoais inseridos pelos usuários para gestão jurídica, administrativa e financeira do escritório.

## Dados tratados

- dados de clientes;
- dados processuais;
- documentos;
- dados financeiros;
- logs de acesso;
- registros LGPD.

## Finalidade

Execução de contrato, exercício regular de direitos, cumprimento de obrigações legais e apoio à gestão jurídica.

## Segurança

São adotados autenticação, controle de permissões, logs, backup e segregação por escritório.

## Retenção

Os dados serão mantidos conforme necessidade contratual, legal e regulatória.

## Direitos do titular

A solicitação deve ser enviada ao escritório controlador dos dados.
